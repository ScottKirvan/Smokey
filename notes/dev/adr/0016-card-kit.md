# ADR-0016: The card is a profile kit, generated in the owner's repo

- Status: Accepted
- Date: 2026-10-09

## Context

The card plays the role Starlines plays today: a scheduled Action that renders images for a profile README. It may need to be more than one SVG.

## Decision

- The card kit is read-only output of the owner's chosen lens.
- It's generated by an Action in the owner's repo, Starlines-style; no server.
- Outputs may include several images and badges, a Markdown fragment for the profile README, and an HTML version for a personal site.

## Consequences

- The card only uses data the owner has marked public.
- Design: [RFC-0002](../rfc/0002-snapshots-card-kit-publishing.md).
